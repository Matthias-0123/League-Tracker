# League Tracker

A simple League of Legends tracker made with Python and FastAPI.

You can search for a player using their Riot ID and tag. The tracker shows:

- Solo Queue rank
- LP and winrate
- Recent matches
- KDA
- Champions and items
- Players from both teams

The project uses the Riot Games API to get player and match data.

## Running the project

Add your Riot API key to a `.env` file:

```text
RIOT_API_KEY=your_api_key
```
